## P0-2 — GitHub merge button policy

### Goal
Repo `fairuzzbd/ifrs9ai`: enable Squash + Create merge commit, DISABLE Rebase merge,
enable auto-delete head branch. Sesuai `git-conventions.md` §"Merge strategy".

### Kenapa orchestrator tidak bisa eksekusi
Ini **GitHub repo settings**, bukan file di repo (no settings-as-code / no GitHub Terraform
provider di workspace). Tidak ada shell/`gh`/GitHub API di toolset orchestrator → **owner =
user (ROLE-IT-ADMIN)**, by design.

### Langkah (user — pilih salah satu)
**A. `gh` CLI (cepat, reproducible):**
```bash
gh repo edit fairuzzbd/ifrs9ai \
  --enable-squash-merge=true \
  --enable-merge-commit=true \
  --enable-rebase-merge=false \
  --delete-branch-on-merge=true
```

**B. `gh api` (eksplisit):**
```bash
gh api -X PATCH repos/fairuzzbd/ifrs9ai \
  -F allow_squash_merge=true \
  -F allow_merge_commit=true \
  -F allow_rebase_merge=false \
  -F delete_branch_on_merge=true
```

**C. Web UI:** Settings → General → Pull Requests:
- ✅ Allow squash merging
- ✅ Allow merge commits
- ⬜ Allow rebase merging (DISABLE)
- ✅ Automatically delete head branches

### Verifikasi
```bash
gh api repos/fairuzzbd/ifrs9ai \
  --jq '{squash:.allow_squash_merge, merge:.allow_merge_commit, rebase:.allow_rebase_merge, autodel:.delete_branch_on_merge}'
# expect: {"squash":true,"merge":true,"rebase":false,"autodel":true}
```
